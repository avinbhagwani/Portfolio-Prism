# Mutual Fund Factor Analysis Dashboard

Streamlit app converted from the Google Colab dashboard.

## Features

- Individual mutual fund analysis
- Portfolio construction with up to 10 funds
- Portfolio weights must total 100%
- Common month-end history for portfolio funds
- CAPM / FF3 / FF4 / FF5 / FF6
- Factor exposure table
- Factor exposure bar chart with coefficient and significance level
- 1/2/3/5/7/10-year rolling regressions
- Portfolio cumulative return chart

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```
